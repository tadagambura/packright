# PackRight

**Packing lists you never write twice**

> #32 of 33 · Wave 3: Seasonal and episodic · Used: Per trip · Very easy · Revenue potential: Low–medium · Plans, Trips & Occasions

## What it is

Reusable packing lists by trip type (beach, city break, festival, ski, business, travelling with a baby) that you tick off as you pack. Lists improve each trip: things you never used drop off, things you forgot get added.

## Why it's in the portfolio

Very quick to build, good search traffic ('festival packing list') and a natural partner to TripSplit and Daymark. Every trip brings users back.

## Who it's for

Holidaymakers, festival-goers, frequent travellers, parents packing for kids.

**The problem:** People rewrite the same list every trip and still forget chargers and passports.

## Version one

- Template lists by trip type
- Tick off while packing; 'pack for home' mode
- Personal lists that improve every trip
- Trip countdown
- Share a list with travel companions

**Example:** Packing for a festival, a user opens their saved festival list, ticks everything off, and adds 'power bank' after forgetting it last year.

## Later

- Weather-aware suggestions
- Shared group lists (sync)
- Hand-luggage liquid and weight checks
