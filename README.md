# PackRight

> **Merged into [Daymark](https://github.com/tadagambura/daymark).**

Packing lists are now a trip template in Daymark: the countdown and the checklist live together. People use packing apps a few times a year and rarely pay.

Decided in the November 2026 portfolio review, based on market research across Reddit, forums,
TikTok/YouTube trends and app-store reviews. This repo is kept for history and is no longer developed.
